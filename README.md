# Yi Liu 的个人主页

一个轻量、响应式的中文个人主页，包含作品、关于和联系方式，并支持深浅色切换。

## 自定义内容

- 在 `index.html` 中修改姓名、介绍、项目和邮箱。
- 在 `style.css` 顶部的变量中修改主色、背景色和文字颜色。
- 示例邮箱是 `hello@example.com`，正式使用前需要替换。

## 已包含

- 桌面端与手机端响应式布局
- 自动跟随系统主题，并可手动切换深浅色
- 键盘焦点、跳转主内容和减少动画支持
- 滚动进入动画与导航位置提示
- 无构建依赖，可直接打开或由任意静态服务器运行

## 本地预览

直接打开 `index.html`，或使用任意静态文件服务器预览。

页面使用 Google Fonts；离线时会自动使用系统字体，不影响内容和布局。
