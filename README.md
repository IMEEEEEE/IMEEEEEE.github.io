# Yi Liu 的创意主页

一个轻量、响应式的多页面个人空间。主页是一座导航大厅，Lab、Model Maker、Music 和 About Me 是四个独立页面。

## 自定义内容

- 在 `index.html` 中修改主页介绍和入口文案。
- 在 `lab.html`、`model-maker.html`、`music.html`、`about.html` 中修改各板块内容。
- 在 `style.css` 顶部的变量中修改主色、背景色和文字颜色。
- 示例邮箱是 `hello@example.com`，正式使用前需要替换。

## 已包含

- 桌面端与手机端响应式布局
- 扁平、明快、带有轻松手绘感的统一视觉
- 四个相互独立又能彼此跳转的内容空间
- 键盘焦点、跳转主内容和减少动画支持
- 无构建依赖，可直接打开或由任意静态服务器运行

## 本地预览

直接打开 `index.html`，或使用任意静态文件服务器预览。

页面使用 Google Fonts；离线时会自动使用系统字体，不影响内容和布局。
